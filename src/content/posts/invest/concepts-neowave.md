# NeoWave

NeoWave is a rigorous extension of Elliott Wave theory that emphasizes objective rules and quantitative validation over subjective interpretation.

## The Time Dimension
The latest evolution in NeoWave analysis (e.g., Structura Wave Engine v18.1) integrates **Time Analysis** as a primary weighting factor alongside Price and Complexity.
- **Time Similarity**: Adjacent waves with similar durations (within 20%) are grouped as structurally related.
- **Symmetry**: Price/Time symmetry is used to project "Thrust Zones" upon triangle breakouts.

## Deterministic Labeling
By applying strict retracement rules (R1-R7) and time symmetry, NeoWave converts wave counting into a probabilistic scoring system rather than a narrative.
