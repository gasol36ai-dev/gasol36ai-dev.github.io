# MLC Law (Morphological Least-Cost Law)

The MLC Law, introduced in Zhu (2026), provides the first rigorous quantitative foundation for Elliott Wave Theory, moving it from subjective pattern matching to deterministic geometry.

## Core Principle
The MLC Law suggests that market structures evolve to minimize "morphological cost"—a measure of the energy/effort required for the market to transition from one state to another. 

## Quantitative Application
- **Wave Validation**: A wave is only valid if its morphology adheres to the least-cost path relative to previous waves.
- **Predictive Power**: By calculating the "cost" of various potential wave paths, traders can assign probabilities to specific wave counts (e.g., a Wave 3 extension vs. a Wave 4 correction).

## Integration with Hermes Logic
The MLC Law can be used as a **structural filter**. If a proposed wave count violates the MLC Law's cost-minimization principle, the count is rejected as "sub-optimal" and marked as low-confidence.
