# Wave Theory: From Elliott to NEoWave

## Elliott Wave Principle (EWP)
The foundation of wave analysis. Based on the premise that markets move in repetitive cycles (5-wave impulse, 3-wave correction).
- **Critique**: Often viewed as subjective; different analysts can see different counts on the same chart.

## NEoWave (The Scientific Evolution)
Developed by Glenn Neely, NEoWave transforms wave analysis into a logical, objective, and self-confirming process.

### Core Principles
1. **Logic over Intuition**: NEoWave removes the \"hope\" of a specific count. It uses a strict set of rules to *verify* a pattern after it has occurred.
2. **Self-Defining**: A pattern is only valid if its internal structure matches the rules of that specific wave type.
3. **Self-Confirming**: The movement *after* the pattern must confirm the pattern's identity (e.g., a completed correction must lead to a trend reversal).

### Advanced 2026 Focus: Double Corrective Structures
Current market regimes are characterized by extreme volatility and "choppy" sideway movement. NEoWave's **Double Corrective Patterns** (complex corrections where one corrective wave is followed by another) are critical for identifying the *actual* end of a consolidation period before a major trend resumes.

### Key Differences
| Feature | Elliott Wave | NEoWave |
| :--- | :--- | :--- |
| **Approach** | Predictive / Intuitive | Verificatory / Logical |
| **Rule Set** | General Guidelines | Strict, Step-by-Step Rules |
| **Validation** | Subjective Interpretation | Post-Occurrence Confirmation |
| **Complexity** | Basic Cycle Patterns | Advanced Complexity & Time Analysis |

## Application in Hermes Strategy
NEoWave is used as a **High-Timeframe Filter**. We do not \"predict\" the wave; we wait for the NEoWave rules to *confirm* the current regime (e.g., \"Double Corrective Structure\") before deploying aggressive capital.
